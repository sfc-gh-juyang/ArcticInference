# Benchmark Result
## Setting 1: Long sequence
* Model: `BAAI/bge-base-en-v1.5`
* Batch size: 16
* Concurrency: 16
* Prompt length: 512
* Device: H200, L40, L4
* Inference server: TEI, vLLM, Arctic Inference

## Setting 2: Short sequence with large batch size (offline embedding)
* Model: `BAAI/bge-base-en-v1.5`
* Batch size: 64
* Concurrency: 256 for A10g, L4 and L40s, 1024 for H200
* Prompt length: 50
* Device: H200, L40, L4
* Inference server: TEI, vLLM, Arctic Inference
